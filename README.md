# Underground Helmet

Underground Helmet is an ESP8266 RTOS SDK project for monitoring safety conditions using sensors and showing the live status on a local web page.

## Features

- MQ gas sensor reading
- DHT temperature and humidity reading
- Ultrasonic distance reading
- 5 LED status indicators
- Buzzer alarm
- Wi-Fi connection to an existing router or phone hotspot
- Local web dashboard
- JSON status API
